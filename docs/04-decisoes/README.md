# Decisões

Espaço para registrar decisões de produto e tecnologia, com contexto e justificativa.

Use arquivos no padrão `NNNN-titulo.md`, com número sequencial. Cada registro deve conter data, status, contexto, alternativas consideradas, decisão, consequências e links para as evidências utilizadas.

**Status:** nenhum registro de decisão nesta pasta. Os princípios iniciais estão no [documento mestre](../00-visao/documento-mestre.md).
